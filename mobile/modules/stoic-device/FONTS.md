# Bundled fonts

`android/src/main/res/font/` contains two fonts used by the native block screen,
so it matches the rest of the app:

- `stoic_fredoka_bold.ttf`: Fredoka Bold, by Milena Brandão
- `stoic_nunito_regular.ttf`: Nunito Regular, by Vernon Adams, Cyreal and Jacques Le Bailly

Both are licensed under the SIL Open Font License 1.1:
https://openfontlicense.org/open-font-license-official-text/

Copied from `@expo-google-fonts/fredoka` and `@expo-google-fonts/nunito`.
